==== 3) Định tuyến theo đường dẫn (header X-Served-By cho biết service nào trả lời) ====
[client]$ for p in / /about /products /static/js/main.js /api/products "/api/orders?page=2" /api; do printf "%-20s -> HTTP %s  %s\n" "$p" "$(curl -s -o /dev/null -w "%{http_code}" "http://domain.com$p")" "$(curl -s -o /dev/null -D - "http://domain.com$p" | grep -iE "^(x-served-by|location)" | tr -d "\r")"; done
/                    -> HTTP 200  X-Served-By: frontend-react:3000
/about               -> HTTP 200  X-Served-By: frontend-react:3000
/products            -> HTTP 200  X-Served-By: frontend-react:3000
/static/js/main.js   -> HTTP 200  X-Served-By: frontend-react:3000
/api/products        -> HTTP 200  X-Served-By: api-gateway:8080
/api/orders?page=2   -> HTTP 200  X-Served-By: api-gateway:8080
/api                 -> HTTP 301  Location: http://domain.com/api/


==== 4) Backend nhận được gì? (cấu hình đầy đủ header) ====
